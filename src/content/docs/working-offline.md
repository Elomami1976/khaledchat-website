> Written for Khaled Chat 0.1.0.

## What works offline

Once a model is downloaded, these work without an internet connection:

- chatting;
- your chat history and search;
- files you add to a chat;
- every setting.

The AI runs on your computer, and your chats are stored there.

## What uses the internet, and only when you choose it

- **You confirm a model download**: the model is downloaded from the host shown in the confirmation
- **You confirm an optional component**: it is downloaded from the hosts shown in its confirmation
- **You turn on Web access** (Settings → Privacy; off by default): the assistant can read web pages you ask about
- **You add a connector or plugin that uses the internet**: it connects to the service you chose; connecting asks first
- **You click a link in a chat**: it opens in your web browser

## What never happens

- No automatic downloads: not at start-up, not after a restart, not in the background.
- No update checks.
- No account, sign-in or cloud AI service.
- No analytics or telemetry.

## Web search

Web search is not available in version 0.1.0 while its licensing is reviewed. With **Web access** on, the assistant can still read pages you give it.
