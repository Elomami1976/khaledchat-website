> Khaled Chat has not been publicly released yet. The steps below describe the intended setup flow and will be verified against the first release build.

## Downloading Khaled Chat

Visit the [Download page](/download/) and choose the installer for your operating system. Only platforms with a published release show an active download button. Where provided, compare the SHA-256 checksum of your download with the value shown on the page.

## Installing the application

Run the installer for your platform and follow the on-screen prompts. Platform-specific instructions will be added with the first release.

## First launch

On first launch, Khaled Chat asks for your first name. This is optional, is stored only on your device, and is used to personalize greetings.

## Hardware detection

Khaled Chat checks your computer's memory, processor, graphics card, video memory, operating system and free storage. This information stays on your device and is used only to recommend suitable models.

## Model recommendation

Based on your hardware, Khaled Chat suggests a model that should run comfortably. Larger models can give better answers but need more memory and run more slowly on limited hardware.

## Downloading the recommended model

The recommended model is downloaded once. Model files can be large, so a stable connection and enough free disk space are required. After the download, the model is configured automatically.

## Starting the first conversation

Type a message in the composer and send it. Responses are generated by the model on your own computer.
