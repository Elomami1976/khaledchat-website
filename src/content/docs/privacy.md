> Khaled Chat is in development and has not been released. This section describes the intended behavior and will be verified against the first release.

For the full policy, see the [Privacy page](/privacy/).

## Local storage

Khaled Chat is designed to store its data on your computer rather than on a remote server.

## Conversation history

Conversations will be saved locally so you can return to them. Deleting the application data will remove them.

## User preferences

Settings, including your optional first name, will be stored on your device.

## File handling

Files you share with Khaled Chat are designed to be processed locally, not uploaded for AI processing.

## Optional network connections

Downloading models and application updates will require a connection to the servers hosting those files. Any future optional online features will be documented here.
